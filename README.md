# KKNL Website (Kusumbha Kalyan Nidhi Limited)

A premium, modern, and highly interactive banking web application for **Kusumbha Kalyan Nidhi Limited (KKNL)**. Built using Next.js 15, TypeScript, Tailwind CSS, and Framer Motion, this platform offers a seamless experience for members seeking mutual savings, high-yield deposit schemes, and loan services.

---

## 🚀 Key Features

* **Interactive Hero & Navigation:** Premium, glassmorphic header navigation with responsive mobile toggles and smooth section scrolling.
* **Animated Stats Counters:** Real-time animated counters displaying trusted members, capital growth, branches, and loan approvals.
* **Interactive EMI Calculator:** Real-time interactive slide-calculator for members to simulate loans, interest rates, tenures, and monthly payouts.
* **Deposit Schemes & Loan Products:** Dynamic product catalogs comparing high-yield savings (FD, RD, MIS) and member-exclusive loan services.
* **Branch Locator:** Information on physical network branches and address details.
* **Lead Generation & Contact Form:** High-conversion contact forms with interactive email/call integrations.
* **Responsive Dark/Gold Aesthetics:** Custom HSL tailored colors, dark mode base, and royal gold accents.

* **Core Framework:** [Next.js 15](https://nextjs.org/) (App Router)

## 📦 Getting Started

### 1. Installation

Clone the repository and install the dependencies:

```bash
npm install
```

### 2. Running Locally

To start the local development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the website in action.

### 3. Building for Production

To create a production build:

```bash
npm run build
```

To run the built production bundle:

```bash
npm run start
```
